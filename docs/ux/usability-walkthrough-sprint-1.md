Simulated Usability Test – Sprint 1

A simulated usability test was conducted using four fictional user profiles between 17 and 55 years old. The purpose was to evaluate the planned Sprint 1 flow:

Login → Find match/stadium → Check-in → Confirmation → Visit History

The simulation focuses on US01, US02, US03, US04 and US06, which form the core Sprint 1 user flow.

Results

All four simulated participants were able to complete the core flow. No major usability problems preventing task completion were identified.

Several minor observations were identified:

One participant briefly hesitated between match and stadium information before starting the check-in.
One participant expected to be automatically redirected to Visit History after completing the check-in.
One participant needed additional time to locate Visit History.
One participant initially overlooked the Check-in button.
Experience Lead Findings

The simulated test indicates that the overall user flow is understandable, but three areas should receive particular attention during implementation and later real-user testing:

1. Check-in visibility
The primary Check-in action should be visually prominent on the match/stadium page.

2. Confirmation and next action
After a successful check-in, the user should receive clear confirmation and an obvious option to view the saved visit.

3. Visit History discoverability
Visit History should be clearly accessible through the main navigation.

Recommended Actions
Keep Check-in as the primary action on the match/stadium screen.
Provide a clear success message after check-in.
Include a "View my visits" action on the confirmation screen.
Keep Visits visible in the main navigation.
Validate these observations with real users once the Sprint 1 implementation is testable.
Conclusion

The simulation suggests that the planned Sprint 1 flow is coherent and that users should be able to complete the main task. The identified observations are minor UX issues rather than blockers. They provide specific points for the Experience Lead to review during implementation and future usability testing.
